# v1.0.0 — Initial public release

> **Status:** Draft. Do not create or publish the tag or GitHub release until
> the remaining launch checks have passed and publication has been explicitly
> approved.

This release presents the independently maintained Gymnasium escape room and
its administration platform as a complete full-stack portfolio project. The
experience is designed for a single event computer and can also be deployed as
a restricted public demonstration.

## Highlights

- Seven configurable game types: quiz, matching, true or false, Pixel Hunt,
  sorting, word assembly and Signalordet.
- Five lives shared across the full session, time-based scoring, penalties,
  retry states and server-verified progression.
- Responsive player experience with keyboard alternatives for drag-based games
  and reduced-motion support.
- Protected administration with autosave, challenge activation, time limits,
  image management, result cleanup and an audit trail.
- Ranked leaderboard with separate event and demo data and automatic retention.
- Hardened public Docker deployment with Caddy-managed HTTPS, secure cookies,
  security headers, rate limiting, private application/database networking and
  persistent data-protection keys.
- Backup, guarded restore and isolated recovery verification for PostgreSQL,
  uploaded images and authentication keys.
- Unit, component, API integration and Playwright tests, including an isolated
  full-stack journey through administration and all seven games.

## Known deployment constraints

- A public demo requires a domain, a Docker-capable host and persistent
  PostgreSQL storage.
- Image replacement uploads should remain disabled on hosts without persistent
  file storage. Bundled challenge images remain playable.
- The application is designed for one event/demo deployment rather than as a
  multi-tenant hosted service.
- Trafikverket names, logos and visual assets remain the property of their
  respective rights holders. No open-source license is granted by this release.
